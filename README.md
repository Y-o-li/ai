# 言之有理 - 浏览器插件操作指南

## 一、插件概述

**言之有理**是一款AI驱动的Chrome浏览器插件，帮助用户识别和分析网页内容中的煽动性语言，并提供事实核查、语义总结和中性化改写功能。

### 核心功能
- **🔍 煽动性语言检测**：基于本地词库实时检测并高亮煽动性词汇
- **✓ 事实核查**：利用大模型分析选中文本的事实准确性
- **☰ 语义总结**：自动生成文本摘要，快速把握核心内容
- **◐ 中性化改写**：将情绪化文本改写为客观中性表达
- **📌 常驻工具栏**：可选常驻模式，随时使用各项功能

---

## 二、安装步骤

### 开发者模式加载

#### 前置条件
- Chrome或Edge浏览器（版本 88+）
- 插件源代码包（从团队共享位置获取）

#### 详细操作步骤

1. **下载并解压插件包**
   ```
   - 解压后目录结构应为：
     frontend-extension/
     └── your-extension/
         ├── manifest.json
         ├── assets/
         ├── background/
         ├── content/
         ├── popup/
         ├── options/
         ├── ui/
         ├── lib/
         └── styles/
   ```

2. **打开浏览器扩展管理页面**
   - Chrome浏览器地址栏输入：`chrome://extensions/`
   - 或通过菜单：`右上角三个点 → 更多工具 → 扩展程序`

3. **开启开发者模式**
   - 在扩展页面右上角找到"开发者模式"开关
   - 点击开启该选项

4. **加载插件**
   - 点击页面左上角的"加载已解压的扩展程序"按钮
   - 在弹出的文件夹选择器中，找到并选择 `your-extension` 文件夹的完整路径
   - 例如：`d:\yanzhi-youli\frontend-extension\your-extension`

5. **确认安装成功**
   - 安装成功后，插件会出现在扩展列表中
   - 浏览器工具栏会出现插件图标（蓝色/紫色渐变的"言之有理"图标）

## 三、初始配置

### 3.1 访问设置页面

首次使用前需要配置API Key：（如不配置，只可使用高亮功能）

- **方法一**：点击浏览器工具栏中的插件图标 → 点击右下角"设置"按钮
- **方法二**：在 `chrome://extensions/` 页面找到"言之有理"插件 → 点击"详细信息" → 点击"扩展程序选项"

### 3.2 配置API Key

#### 选择AI服务提供商

插件支持以下三个国内大模型服务：

| 提供商 | 模型名称 | 推荐指数 | 特点 |
|--------|---------|---------|------|
| 通义千问 | qwen-turbo | ⭐⭐⭐⭐⭐ | 响应快，性价比高 |
| 通义千问 | qwen-plus | ⭐⭐⭐⭐ | 能力更强，速度适中 |
| 通义千问 | qwen-max | ⭐⭐⭐ | 最强模型，响应较慢 |
| 智谱GLM | glm-4 | ⭐⭐⭐⭐ | 综合表现优秀 |
| 文心一言 | ernie-bot | ⭐⭐⭐⭐ | 中文理解能力强 |

建议：日常使用推荐 **qwen-turbo**，复杂任务选择 **qwen-plus** 或 **glm-4**

#### 获取API Key

1. **通义千问（阿里云）**
   - 访问：https://dashscope.aliyun.com/
   - 注册/登录阿里云账号
   - 进入控制台，创建API Key
   - 复制API Key（格式：sk-xxxxxxxx）

2. **智谱GLM**
   - 访问：https://open.bigmodel.cn/
   - 注册/登录智谱AI账号
   - 进入API Key管理页面
   - 创建并复制API Key

3. **文心一言（百度）**
   - 访问：https://cloud.baidu.com/product/wenxinworkshop
   - 注册/登录百度智能云账号
   - 开通文心一言服务
   - 获取API Key和Secret Key

#### 填写配置

1. 在设置页面的"API配置"区域：
   - **选择AI提供商**：从下拉菜单选择您使用的服务
   - **模型版本**：根据需求选择合适的模型版本
   - **API Key**：粘贴您的API Key（显示为密码形式，可点击眼睛图标切换显示）
   - **Secret Key**：仅文心一言需要填写

2. 点击"测试连接"按钮验证配置
   - 成功会显示绿色提示："✅ 连接成功！"
   - 失败会显示红色提示："❌ 连接失败"及错误信息

3. 配置完成后点击右下角"保存设置"按钮

#### API Key安全说明

- API Key仅存储在您的浏览器本地（chrome.storage.local）
- 不会上传到任何第三方服务器
- 不会与其他用户共享
- 建议定期更换API Key以提高安全性

## 四、功能使用指南

### 4.1 煽动性语言检测

**功能说明**：自动检测网页中的煽动性词汇并进行高亮显示（本地处理，无需消耗API调用次数）

**使用方法**：

1. 确保在设置中"煽动性语言检测"开关已开启
2. 正常浏览任意网页
3. 插件会自动扫描页面内容
4. 检测到的煽动性词汇会用**黄色背景**高亮显示
5. 鼠标悬停在高亮词上会显示检测详情

**性能说明**：
- 仅对当前可视区域进行检测
- 滚动页面时会动态检测新内容
- 不消耗API额度，完全免费使用

---

### 4.2 浮动工具栏

**功能说明**：选中文本后出现的工具栏，提供事实核查、语义总结、中性化改写功能

#### 标准模式（默认）

1. 在网页上选中任意一段文本
2. 选中文本后，会在选区上方自动显示浮动工具栏
3. 工具栏包含四个按钮：
   - **事实核查**：分析文本的事实准确性
   - **语义总结**：生成文本摘要
   - **中性化改写**：改写为中性表达
   - **关闭**：隐藏工具栏

4. 点击功能按钮后，等待处理完成
5. 结果会以卡片形式展示在工具栏下方

#### 常驻模式（可选）

**适用场景**：频繁使用插件功能的用户

**开启方法**：
1. 进入设置页面
2. 在"功能设置"区域找到"始终显示工具栏"
3. 打开开关并保存设置

**常驻模式特点**：
- 工具栏固定显示在页面顶部中央
- 无需选中文本即可使用
- 选中文本时工具栏会自动移动到选区上方（智能跟随）
- 不会因为滚动或点击页面其他区域而隐藏

**关闭方法**：
- 在设置页面关闭"始终显示工具栏"开关
- 或点击工具栏右侧的关闭按钮

---

### 4.3 事实核查

**功能说明**：利用大模型对选中文本进行事实准确性分析，评估内容的可信度并提供相关证据

**使用步骤**：

1. 选中需要核查的文本（建议200-500字）
2. 在浮动工具栏点击"事实核查"按钮
3. 等待处理（通常3-10秒）
4. 查看返回的事实核查结果

**结果内容**：
- **可信度评估**：高/中/低三个等级
- **事实分析**：对内容中关键陈述的分析
- **证据来源**：相关参考资料或数据来源
- **风险提示**：可能的误导性内容警告

**使用技巧**：
- 核查新闻标题或摘要时，建议同时查看全文
- 对于争议性话题，可尝试多个不同来源的文本进行对比
- 如结果不确定，建议进一步查证官方信息

---

### 4.4 语义总结

**功能说明**：自动生成长文本的精炼摘要，帮助快速把握核心信息

**使用步骤**：

1. 选中需要总结的文本（建议500-2000字）
2. 在浮动工具栏点击"语义总结"按钮
3. 等待处理（通常2-8秒）
4. 查看生成的摘要内容

**结果内容**：
- **核心观点**：文本的主要论点或结论
- **关键信息**：重要的事实、数据或事件
- **结构化摘要**：分条列出主要内容的概述

**使用技巧**：
- 总结长篇文章时，可分段选中分别总结
- 对于技术文档，建议选中包含方法、步骤的段落
- 生成摘要后可复制用于笔记或分享

---

### 4.5 中性化改写

**功能说明**：将情绪化、煽动性文本改写为客观中性的表达，去除主观色彩

**使用步骤**：

1. 选中需要改写的文本
2. 在浮动工具栏点击"中性化改写"按钮
3. 等待处理（通常2-8秒）
4. 查看改写后的文本

**结果内容**：
- **中性化文本**：去除情绪词汇后的客观表述
- **改动说明**：标注被替换的煽动性词汇及替换原因
- **对比展示**：可选显示原文和改写后文本的对比

**使用场景**：
- 将网络评论中的攻击性语言改为理性表达
- 将带有明显倾向的报道改写为客观描述
- 将过于情绪化的文案改为专业表述

---

### 4.6 结果卡片操作

**功能说明**：展示大模型处理结果的浮动卡片

**卡片功能**：
- **复制结果**：点击卡片底部的"复制"按钮，将结果复制到剪贴板
- **关闭卡片**：点击右上角的×号关闭卡片
- **重新处理**：点击工具栏按钮可重新执行操作

**卡片样式**：
- 采用现代化设计，圆角卡片
- 支持Markdown格式渲染
- 可调整卡片位置（拖拽标题栏）

## 五、常见问题（FAQ）

### Q1: 插件加载后图标显示但无法使用？

**A**: 请检查以下步骤：
1. 确认是否已配置API Key
2. 检查API Key是否有效（测试连接）
3. 刷新页面后重试

### Q2: 测试连接失败怎么办？

**A**: 可能的原因和解决方案：
- **API Key无效**：重新复制正确的API Key
- **网络问题**：检查网络连接，尝试切换网络
- **服务商问题**：检查服务商服务是否正常
- **模型选择错误**：确认选择的模型与服务商匹配

### Q3: 点击功能按钮后没有响应？

**A**: 请检查：
1. 确认选中文本长度适中（建议50-2000字）
2. 查看浏览器控制台是否有错误信息（F12打开控制台）
3. 检查API余额是否充足
4. 尝试刷新页面后重试

### Q4: 处理结果不准确怎么办？

**A**: 建议：
1. 尝试切换到更强大的模型（如qwen-plus、qwen-max）
2. 将文本分段处理
3. 尝试提供更多上下文信息
4. 对于事实核查，建议参考多个来源

### Q5: 插件影响页面加载速度？

**A**:
- 煽动性语言检测采用本地匹配，影响较小
- 大模型功能仅在用户主动点击时触发，不影响正常浏览
- 如感觉卡顿，可在设置中关闭"煽动性语言检测"

### Q6: 可以在哪些网站使用？

**A**:
- 插件支持所有HTTPS和HTTP网站
- 部分特殊网站（如chrome://、chrome-extension://）可能受限
- 某些网站的复杂结构可能影响选中文本检测

### Q7: API使用量如何查看？

**A**:
- 登录对应AI服务商的控制台
- 查看API调用统计和账单
- 建议设置使用限额和告警

### Q8: 卸载插件后数据会保留吗？

**A**:
- API Key等配置存储在浏览器本地，卸载后会被清除
- 如需重新安装，需重新配置API Key
- 建议备份重要的API Key信息

### Q9: 常驻工具栏遮挡页面内容怎么办？

**A**:
- 暂时关闭：点击工具栏关闭按钮
- 永久关闭：在设置中关闭"始终显示工具栏"
- 未来版本将支持拖拽调整位置

### Q10: 如何更新到最新版本？

**A**:
- 开发者模式加载：重新加载插件（在扩展页面点击刷新按钮）
- 应用店安装：浏览器会自动更新

## 六、高级技巧

### 6.1 提高处理效率

1. **选中文本技巧**
   - 避免选择过长文本（建议<2000字）
   - 选择关键段落而非整页内容
   - 排除无关的广告、导航文本

2. **模型选择建议**
   - 快速浏览：使用qwen-turbo
   - 深度分析：使用qwen-plus或glm-4
   - 复杂任务：使用qwen-max

3. **批量处理**
   - 对同一篇长文的不同部分分别使用不同功能
   - 先进行事实核查，再进行总结

### 6.2 组合使用功能

**典型工作流**：

1. **阅读新闻文章**
   - 开启煽动性语言检测（自动高亮）
   - 选中文本进行事实核查
   - 对关键段落进行语义总结

2. **分析社交媒体评论**
   - 开启煽动性语言检测
   - 对争议评论使用中性化改写
   - 对长评论进行事实核查

3. **研究技术文档**
   - 对长文档分段进行语义总结
   - 对技术说明进行事实核查
   - 对复杂表述使用中性化改写

## 七、故障排查

### 7.1 查看错误日志

1. 按 `F12` 打开浏览器开发者工具
2. 切换到 `Console` 标签
3. 查找以 `[言之有理]` 开头的日志
4. 如有红色错误信息，截图反馈给开发团队

### 7.2 常见错误代码

| 错误代码 | 含义 | 解决方案 |
|---------|------|---------|
| API_KEY_INVALID | API Key无效 | 重新配置正确的API Key |
| QUOTA_EXCEEDED | API配额用尽 | 充值或等待下月重置 |
| NETWORK_ERROR | 网络错误 | 检查网络连接 |
| TIMEOUT | 请求超时 | 减少文本长度或重试 |
| RATE_LIMIT | 请求频率过高 | 等待几秒后重试 |

### 7.3 重置插件

如遇到无法解决的问题，可尝试重置：

1. 在 `chrome://extensions/` 页面点击"移除"
2. 重新加载插件
3. 重新配置API Key和设置

## 八、安全与隐私

### 数据处理说明

1. **文本上传**
   - 仅用户选中的文本会被上传到AI服务商
   - API Key存储在本地，不会与插件开发者共享
   - 处理结果仅存储在浏览器本地内存中，刷新页面后清除

2. **数据保留**
   - AI服务商可能根据其隐私政策记录请求数据
   - 建议不要上传敏感个人或机密信息
   - 定期清理服务商的控制台数据

3. **权限说明**
   - `activeTab`：读取当前标签页内容
   - `storage`：存储API Key和用户设置
   - `scripting`：注入脚本实现功能
   - `<all_urls>`：在所有网站运行
